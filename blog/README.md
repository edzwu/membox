# Agora

Clean-slate Hugo notes MVP.

## Local Development

```bash
hugo server --baseURL http://localhost:1313 --disableFastRender
```

## Build

```bash
hugo --minify
# or via the Rust CLI wrapper:
./ag build
```

The build output is generated by Hugo.

## Git Hooks

A pre-commit hook in `.githooks/` runs `hugo --minify` to verify the site builds before every commit. Enable it once per clone:

```bash
git config core.hooksPath .githooks
```

## Deploy

Deployment is automated by GitHub Actions in `.github/workflows/deploy.yml`.

This repository builds the Hugo site and publishes the `public/` output to `edzwu/edzwu.github.io`.

### One-time GitHub setup

1. Create a fine-grained personal access token that can write to `edzwu/edzwu.github.io`.
2. In this repository (`edzwu/agora`), add repository secret `PAGES_DEPLOY_TOKEN`.
3. If you already use `DEPLOY_PAT` from older repositories, you can keep using it (workflow supports both names).
4. Ensure the destination repository `edzwu/edzwu.github.io` publishes from branch `master`.

After that, every push to `main` in this repository triggers a build and deploy. The site will be available at `https://edzwu.github.io/`.
