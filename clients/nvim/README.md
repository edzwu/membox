# Neovim client (v0.1)

This is a thin UI for the Python core.

Dev install:
```vim
set rtp+=/path/to/membox_v0_1/clients/nvim
```

Commands:
- `:Membox` (alias `:Mm`)

Prompt examples:
- `task ls`
- `task add "hello"`
- `task done 1`

Result keys:
- `d` mark done on selected row
- `r` refresh
- `q` close UI tab
