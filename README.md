# Agora

Clean-slate Hugo notes MVP.

## Local Development

```bash
hugo server --baseURL http://localhost:1313 --disableFastRender
```

## Build

```bash
npm run build
```

The build output is generated by Hugo.

## Deploy

Deployment uses GitHub Pages Actions in [.github/workflows/deploy.yml](.github/workflows/deploy.yml) and no longer depends on personal access tokens or external repositories.
